# AI Readiness & Quality Engineering Assessment Platform — planning repository

**Status: specification and Claude Code preparation only. No application has been built or tested.**

## Start in VS Code
1. Extract the ZIP, open `ai-readiness-qa-platform/` in VS Code, and inspect `CLAUDE.md`.
2. Put separately approved research and content artifacts in `docs/research/approved/` (do not substitute guesses).
3. Launch Claude Code and select **Plan Mode** using the interface supported by your installed version.
4. Paste `docs/roadmap/CLAUDE_PLAN_MODE_PROMPT.md` and ask Claude to review the repository.
5. Approve or amend the proposed plan **before** allowing code generation, dependency installation, database changes, or deployment.

## Document map
`docs/requirements/` product requirements and traceability; `docs/architecture/` diagrams and ADRs; `docs/database/` proposed schema and queries; `docs/api/` API contract; `docs/design-system/` UX; `docs/testing/` test strategy; `docs/roadmap/` execution gates; `.claude/` agents and skills.
